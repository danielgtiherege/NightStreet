# NightStreet

NightStreet is a simple OpenGL tech demo and lightweight benchmark tool for Windows, written in a single C source file with minimal dependencies.

Inspired by 1990s hardware demos, it features a nighttime city with textured buildings, parked vehicles, flickering streetlights, and an automated camera that follows a floating ship as it passes.

Features include:

- Classic OpenGL rendering with GLFW.
- OBJ/MTL model loading and JPG/PNG textures.
- Display lists and optional frustum culling.
- Fullscreen mode at the monitor’s resolution.
- An on-screen display showing resolution, FPS, culling, and VSync status.

Use:

ESC exit | SPACE pause | R restart path | V VSync | UP/DOWN speed | F wire-frame | C culling
ALT+ENTER OR double mouse click: FullScreen/Window.
